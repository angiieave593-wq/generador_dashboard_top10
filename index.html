Arma el dashboard de transaccionalidad en segundos

Carga la base de clientes en Excel y el tablero se construye solo, con filtros, comparativos y tasa de crecimiento. El archivo se procesa en tu navegador: los datos no se suben a ningún servidor.

Columnas que debe tener la base
SERVICIO TIPO CLIENTE NOMBRE DIRECTO/ALIANZA (opcional) CLIENTE ENERO FEBRERO … un mes por columna

Los meses se detectan solos, en cualquier cantidad. Las filas sin servicio o sin cliente (como la fila de totales) se ignoran. El año se toma del nombre del archivo, por ejemplo Base_2026_AGOSTO.xlsx.
